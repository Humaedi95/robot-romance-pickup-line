A single pickup line to charm a robot — one line, under 200 characters, built
around the machine premise itself: prompts, autocomplete, and the token limit.

## How to run

```sh
node main.ts
```

It writes exactly the one pickup line plus a trailing newline to
`/output/entry.txt`.
